My Final Year Project at NUS (in progress): a type checker in OCaml for a subset of TypeScript, built on set-theoretic types where union, intersection, and negation are true set operations. Subtyping, match exhaustiveness, and branch reachability all reduce to a single emptiness test. The flow-insensitive checker works today.
